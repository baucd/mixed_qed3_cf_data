# mixed_qed3_cf_data

Data repository for the accepted PRX paper on mixed QED$_3$ and the chiral-flux phase. It contains selected numerical data used to prepare figures in the paper and Supplemental Material, including DQMC summaries, correlation data, and mean-field and QMC+SAC spectra.

The complete bin-resolved DQMC outputs and the imaginary-time Green functions used for SAC are available from the authors upon reasonable request.
